# テストフィードバック管理

テスターからのリクエスト・質問・バグ報告を一覧で蓄積し、対応状況を追うための台帳です。
一覧は [`FEEDBACK.csv`](./FEEDBACK.csv)（GitHub上で表として閲覧可・Google Sheets/Excelにも取込可）。

## 運用フロー
1. **受付**：リクエスト/質問/バグが来たら、`FEEDBACK.csv` に **原文ママ**で1行追記する（要約しない・言い換えない）。
2. **仕分け**：
   - **バグ系** → 速攻で直す。
   - **判断が必要** → ステータス `要判断` にして依頼者（オーナー）に仰ぐ。
   - **後回しでよい** → ステータス `後回し`。
3. **修正**：着手したら `対応中`、直したら `修正完了`列に ✓・ステータス `修正完了`（コミットSHAを対応メモへ）。
4. **確認**：オーナー確認でOKなら `確認完了`列に ✓・ステータス `完了`。

## 列の意味
| 列 | 内容 |
|---|---|
| ID | 連番（1, 2, 3…） |
| 受付日時 | `YYYY-MM-DD HH:MM` |
| 種別 | `バグ` / `質問` / `要望` |
| 内容（原文ママ） | テスターの発言を一言一句そのまま。ダブルクオートで囲む |
| 優先度 | `高` / `中` / `低` |
| ステータス | `未対応` / `対応中` / `要判断` / `後回し` / `修正完了` / `完了` |
| 修正完了 | 直したら `✓` |
| 確認完了 | オーナー確認OKで `✓` |
| 対応メモ | 対応内容・コミットSHA・判断待ちの論点など |

## 使い方（オーナー）
- テスターの声（テキスト/スクショ）を Claude に渡すだけでOK。Claude が原文ママでCSVに追記し、バグは即修正、判断が要るものは質問を返します。
- 進捗は `FEEDBACK.csv` を開けば一覧で確認できます。
