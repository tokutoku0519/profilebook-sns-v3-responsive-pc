# プライバシーポリシー・利用規約 改訂案（自由回答の翻訳機能）

状態：**案**。外部の翻訳サービス（Claude Haiku 5.5）を使い始める前に、法律の専門家の確認を経て `src/app/privacy/page.tsx`・`src/app/terms/page.tsx` に反映する。
仮の翻訳（外部へ送らないテスト版）だけを使っている間は、改訂しなくても現行の記載と矛盾しない。

---

## 1. 前提（実装している仕組み）

| 項目 | 内容 |
|---|---|
| 翻訳サービスの事業者 | Anthropic, PBC（米国）。モデル：Claude Haiku 5.5（API 経由） |
| 送る情報 | 翻訳を許可した人の、公開しているプロフ帳の自由回答（ひとこと・自己紹介・好きなもの・BEST3・ひとこと質問の回答など）と、公開したお題への回答。手がかりとして、その質問文 |
| 送らない情報 | 名前・ニックネーム・ユーザー ID・メールアドレス・誕生日などの登録情報、フォロワー限定・非公開の内容、日記・ブログ・コメント、閲覧者の情報（誰が翻訳を見たか） |
| 送るタイミング | ほかの言語で見ている人が「翻訳を見る」を押したとき。ただし同じ内容・同じ言語の翻訳がすでにあれば送らない |
| 送り先の国・地域 | 米国（Anthropic のサーバー） |
| 保存・学習 | API の入力・出力は、受信または生成から 30 日以内に自動削除（Anthropic の標準。利用規約違反の調査などで長く保存されることがある）。明示的な許可なしにモデルの学習には使われない |
| 利用しない選択肢 | 書いた人：マイページの「翻訳を許可する」をオフにする（初期値はオフ。オフなら一切送らない）。読む人：「翻訳を見る」を押さなければ送られない |
| 原文と翻訳の扱い | 原文は変更しない。翻訳結果は Miri のデータベースに保存し、同じ内容の翻訳に使い回す。原文の編集・公開範囲の変更・許可の取り消し・退会で自動的に削除する |

> 確認が必要な点
> - Anthropic の保存期間・学習利用の条件は、契約時点の公式ページ（privacy.claude.com、商用規約）で最新の内容を確認すること。
> - 外国にある第三者への提供（個人情報保護法 28 条）に当たるかどうか、委託として扱えるかどうかは、法律の専門家に確認すること。案では、本人の同意（「翻訳を許可する」）を取り、28 条 2 項の情報提供をする形にしている。
> - 海外（EU など）の利用者がいる場合、その国の法令（GDPR など）への対応が必要か確認すること。
> - 未成年の利用者が多い想定のため、同意の画面の文言が分かりやすいかを確認すること。

## 2. プライバシーポリシーの改訂案

### 2-1.「当社は、取得した情報を次の目的で利用します」に追加

> ・ユーザーが許可した場合に、公開されたプロフィール帳の回答・お題への回答を、他の言語で閲覧するユーザーのために翻訳して表示すること

### 2-2. 新しい項目「翻訳機能について」（「委託」の次に追加）

> **翻訳機能について**
>
> 1. 本サービスには、他の言語で閲覧するユーザーが、ユーザーの公開している回答を翻訳して読める機能（以下「翻訳機能」といいます）があります。翻訳機能は、回答を書いたユーザーが本サービス上の設定で「翻訳を許可する」を選んだ場合にのみ利用されます（初期設定は「許可しない」です）。
> 2. 翻訳の対象は、プロフィール帳のうち公開設定（または公開範囲を設定していない）の自由記入の回答（ひとこと、自己紹介、好きなもの・嫌いなもの、BEST3、ひとこと質問への回答等）、および公開設定で投稿したお題への回答です。ニックネーム、氏名、ユーザーID、メールアドレス、誕生日、フォロワー限定・非公開の内容、日記、ブログ、コメントは翻訳の対象にしません。
> 3. 翻訳は、他の言語で閲覧するユーザーが「翻訳を見る」を選んだときに行います。翻訳のため、対象の文章とその質問文を、次の翻訳サービスの提供事業者に送信します。同じ文章・同じ言語の翻訳がすでにある場合は送信しません。
>    - 提供事業者：Anthropic, PBC
>    - 所在国：アメリカ合衆国
>    - 送信する情報：翻訳の対象となる文章、その質問文、翻訳先の言語（ユーザーを特定する情報は送信しません）
>    - 提供事業者における取扱い：送信された文章は翻訳結果の生成に使われ、提供事業者の定めに従い原則として 30 日以内に削除されます（利用規約違反への対応等のために、より長く保存される場合があります）。提供事業者は、明示的な許可なく送信された文章をAIの学習に利用しません。
> 4. アメリカ合衆国の個人情報の保護に関する制度については、個人情報保護委員会が公表している情報【リンク】をご覧ください。提供事業者は、【個人情報の取扱いに関する措置の概要。契約・公表情報を確認して記載】の措置を講じています。
> 5. 翻訳結果は、同じ文章を翻訳する際に再利用するため当社のデータベースに保存します。元の文章が編集・削除されたとき、公開範囲が変更されたとき、翻訳の許可を取り消したとき、または退会したときは、保存した翻訳結果を削除します。元の文章は翻訳によって変更されません。
> 6. ユーザーは、いつでも本サービス上の設定で翻訳の許可を取り消すことができます。取り消した後は、そのユーザーの文章は送信されません。閲覧するユーザーは、「翻訳を見る」を選ばなければ翻訳機能を利用しません。
> 7. 翻訳は機械によるものであり、内容の正確さを保証するものではありません。人名・作品名等の固有名詞は原文のまま表示することがあります。

### 2-3.「委託」の項目に追記

> 当社は、翻訳機能の提供のため、前項に定める翻訳サービスの提供事業者に文章の処理を委託（または同項の同意に基づき提供）することがあります。

### 2-4.「保存期間」の項目に追記

> 翻訳結果は、元の文章の編集・削除、公開範囲の変更、翻訳の許可の取り消し、退会のいずれかがあった時点で削除します。

## 3. 利用規約の改訂案

### 3-1.「本サービスの内容」の公開範囲の段落の後に追加

> 本サービスには、他の言語で閲覧するユーザーのために、ユーザーが公開した回答を機械翻訳して表示する機能があります。この機能は、回答を書いたユーザーが翻訳を許可した場合にのみ利用されます。翻訳の内容は機械によるものであり、当社はその正確性を保証しません。詳細はプライバシーポリシーに定めます。

### 3-2.「コンテンツの権利」の利用許諾の範囲

現行：「本サービスの提供・改善・宣伝…に必要な範囲で…利用（複製、翻案、公衆送信…）する権利を許諾」
→ 翻訳は「翻案」に含まれ、翻訳機能は「本サービスの提供」に当たるため、**現行の文言の範囲内**。分かりやすさのため、括弧内に「翻訳」を加える案：

> …利用（複製、翻案（翻訳を含みます）、公衆送信、第三者への再許諾を含みます）…

## 4. 現行の規約・ポリシーとの整合性の確認

| 現行の記載 | 翻訳機能との関係 | 対応 |
|---|---|---|
| ポリシー「公開される主な情報」：公開設定の項目は第三者が閲覧できる | 翻訳するのは公開の内容だけ（フォロワー限定・非公開は対象外）。公開の範囲は広がらない | そのまま |
| ポリシー「項目ごとに公開／フォロワー限定／非公開」 | 翻訳も同じ設定に従う。未設定は「本人の許可があるときだけ」対象 | 2-2 の 2 に明記 |
| ポリシー「委託」：クラウド・DB 事業者のみ | 翻訳サービスが新しく加わる。外国の事業者 | 2-2・2-3 で追加。28 条の扱いは専門家に確認 |
| ポリシー「利用目的」 | 翻訳は「本サービスの提供」に含まれるとも読めるが、明示する | 2-1 で追加 |
| ポリシー「保存期間」：退会等で消去 | 翻訳結果も退会・取り消しで削除（実装済み） | 2-4 で明記 |
| ポリシー「第三者提供」：同意なく提供しない | 外国にある第三者への提供に当たる場合は同意が必要。「翻訳を許可する」がその同意になるよう、画面にも送信先を表示している | 画面の文言（tr_consent_desc・tr_consent_ext）を専門家に確認してもらう |
| ポリシー「未成年者」：法定代理人の同意 | 翻訳の許可も同じ扱い | そのまま（必要なら画面に一言加える） |
| 規約「コンテンツの利用許諾（翻案を含む）」 | 翻訳は翻案 | 範囲内。3-2 で明示する案 |
| 規約「データの収集（スクレイピング等）の禁止」 | 翻訳 API の大量呼び出しも不正利用に当たる | そのまま（API 側でも回数制限を実装済み） |

## 5. 画面の表示（実装済み・文言は要確認）

- マイページ「プロフ帳と回答の翻訳」：翻訳される内容、送らない情報、「翻訳するときは、その文章が翻訳サービス（AI）に送られます。オフにすると送られません。」を表示。初期値はオフ。
- 翻訳を表示したとき：「AIによる翻訳です。名前や作品名は原文のまま残すことがあります」（仮の翻訳のときは「テスト用の仮翻訳です」）。
- 本番で外部サービスを使い始める前に、マイページの説明に送信先（Anthropic・米国）とプライバシーポリシーへのリンクを加える。
